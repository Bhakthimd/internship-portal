# Internship Portal

## Project Overview

Internship Portal is a simple website created using HTML and CSS.

The website provides information about internship opportunities and contains
the following sections:

- Home
- About
- Internship Programs
- Team
- Contact

The main purpose of this project was to learn and demonstrate the Git and
GitHub development workflow.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## How to Run the Project

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation is required.
